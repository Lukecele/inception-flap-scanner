# Contributing to Inception Flap Scanner

We welcome open-source contributions to improving on-chain security, bonding curve telemetry, and launch detection on BNB Smart Chain.

## How to Contribute
1. Fork this repository.
2. Create a feature branch: `git checkout -b feat/your-feature-name`.
3. Ensure all tests pass (`npm test`) and linter checks pass (`npm run lint`).
4. Commit your changes following standard conventional commit messages (`feat:`, `fix:`, `docs:`, `refactor:`).
5. Open a Pull Request against `main` with a concise explanation of the changes.

## Security Disclosures
For security vulnerabilities, please refer to [SECURITY.md](./SECURITY.md) instead of creating public issues.
