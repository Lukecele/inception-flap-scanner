# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | ✅        |

## Reporting a Vulnerability

If you discover a security vulnerability or responsible disclosure vector, please do NOT open a public GitHub issue.

Please report vulnerabilities directly to:
- **Email:** `security@arbitrage-inc.exchange`
- **Telegram:** [Arbitrage Inception Telegram](https://t.me/ArbitrageInception)

### What to Include
- Detailed description of the potential vulnerability
- Steps or proof-of-concept to reproduce
- Potential severity and impact assessment
- Suggested remediation (if available)

We acknowledge security reports within 48 hours and coordinate fixes before public announcement.

## Scope
- Frontend and backend proxy engine in this repository
- Bonding curve and telemetry algorithms
- Security audit modules
